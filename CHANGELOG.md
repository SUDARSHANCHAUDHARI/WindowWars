# Changelog

All notable changes to WindowWars are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-19

### Added

- Responsive illustrated room with an interactive SVG window and storm
- Click, drag, touch, and keyboard controls
- Ten randomized window interruption performances and attempt tracking
- Guaranteed calm victory state on the tenth close
- Procedural rain, wind, thunder, and event audio with a sound toggle
- Reset behavior and reduced-motion support
- Pure state reducer, shuffled event deck, and automated contract tests
- Deterministic static production build, security metadata, and deployment guidance
